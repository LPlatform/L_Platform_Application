# Security policy

This public repository has no released supported version yet. Report vulnerabilities privately through GitHub Security Advisories when enabled, or contact repository owners using an established private channel. Do not publish exploit details in an issue. Include affected revision, impact and reproducible steps; never include user data, credentials or private backend implementation details.

Revoke and rotate exposed credentials immediately. Never commit API/OCI/database credentials, signing keys, private tests, backend source or confidential organization configuration. Security scanning and push protection depend on GitHub plan/settings and are not enabled merely by workflow files.
