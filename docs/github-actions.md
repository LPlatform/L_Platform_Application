# GitHub Actions

`ci.yml` runs only bootstrap-policy smoke tests. Rust and native-build checks are separate jobs and display `skipped` until a Cargo workspace or pnpm project is present; once initialized they run pinned Rust fmt/clippy/tests and real Windows/Linux frontend tests/builds. Dependabot performs weekly npm/Cargo/Actions updates; CI reviews their PRs. The redundant scheduled readiness workflow was removed. Release tags use `app-vX.Y.Z`; native runners require real installer files, generate SHA-256 checksums and attach assets only after all checks succeed. macOS remains optional; Linux ARM64 is not enabled without dependency verification.

The current run proves only two bootstrap policy smoke tests. It did not run React or Rust tests, Tauri config validation, or a production build; the native/Rust matrix jobs are skipped and must not be described as successful builds. The Rust compiler is pinned to 1.99.1 and Node to 24.22.1. Public-repo secret scanning and push protection are enabled. The release tag pattern has an active tag ruleset blocking updates/deletion. `CHANGELOG.md` is not rewritten; GitHub release notes are generated. No signing credentials or updater config exist.
